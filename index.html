01 — role fit

The ₱35k role is a good bridge—if the scope is real.

Infrastructure experience strengthens cloud security when it gives you ownership of identity, networks, systems, logging, hardening, backup, or automation.

✓
Recommended decision

Take the offer if the responsibilities below are genuinely available, the compensation terms are acceptable, and there are no serious contract or culture red flags. Use the first year as paid systems training—not as a pause in your security career.

01 — operate

Own the fundamentals

Windows/Linux, AD or Entra, DNS, DHCP, VLANs, endpoints, patching, backup, virtualization, and troubleshooting.

02 — secure

Add security thinking

Least privilege, MFA, RBAC, hardening, vulnerability remediation, logging, incident handling, and recovery.

03 — automate

Make work repeatable

PowerShell first, then Bash/Python and infrastructure-as-code. Measure time saved, risk reduced, and reliability improved.

Infrastructure opportunity score

Tick what the role can realistically expose you to within 6–12 months.

opportunity strength

02 — first 90 days

Start small enough to finish.

Use one main study track at a time. If Security+ is already complete, move Network+ forward; if your employer uses Azure daily, accelerate AZ-104 labs.

30
days 01–30 · orient

Learn the environment and finish the quick cloud baseline.

Map the systems you support, understand escalation and change processes, and complete AZ-900 preparation without letting it consume the quarter.

60
days 31–60 · strengthen

Build the security and automation layer.

Make Security+ your main paid exam unless it is already done. Practice PowerShell and Linux against work-like tasks.

90
days 61–90 · prove

Turn learning into a visible hiring signal.

Show one project, one operational improvement, and one clear interview story. Continue targeted applications instead of waiting for every certificate.

05 — portfolio labs

One visible artifact per major learning block.

Sanitize everything: never publish employer data, credentials, customer information, proprietary screenshots, or internal network details.

lab 01 · foundation

Network troubleshooting case

Simulate a DNS, routing, firewall, or VLAN fault and show the checks that isolate it.

publish Diagram, packet path, commands, evidence, fix, and prevention.
lab 02 · identity

AD / Entra identity hardening

Create users, groups, role separation, MFA/conditional-access design, and an access review.

publish Access model, risks, controls, screenshots with sensitive data removed.
lab 03 · automation

PowerShell operations helper

Inventory services, summarize event logs, check backups, or report patch state using safe sample inputs.

publish Script, README, sample output, error handling, and rollback notes.
lab 04 · cloud

Secure Azure baseline

Use Entra, RBAC, Policy, VNet/NSG, Key Vault, Monitor, backup, and budgets in one small design.

publish Architecture, IaC, controls, cost estimate, validation, and teardown.
lab 05 · blue team

SIEM investigation

Investigate a suspicious login, PowerShell execution, phishing message, or malware alert.

publish Timeline, query, evidence, ATT&CK mapping, decision, and response.
lab 06 · emerging

AI workflow threat model

Model prompt injection, data exposure, excessive agency, tool abuse, identity, logging, and human approval.

publish Data-flow diagram, abuse cases, risk ranking, and mitigations.

A faster path is possible, but certificates alone rarely create the jump. The leverage comes from production scope, visible proof, targeted applications, and changing roles when your evidence outgrows your pay.

09 — weekly planner

Keep work, learning, and job search moving together.

Save a lightweight plan locally. A sustainable default is 6–8 focused hours per week outside work, with only one main exam track.

Personal plan

Set the next role and the one credential that currently matters most.

Impact log

Capture problem, action, technology, result, and lesson. Use honest scope when a numeric metric is unavailable.

Weekly minimum

Reset these manually each week; consistency is more useful than an unrealistic daily streak.

Decision rule

Do not add a new paid credential unless it passes at least two tests:

It appears repeatedly in the roles you want.
It validates skills you can practice or use now.
An employer or voucher reduces the cost.
It creates proof beyond your existing credentials.
